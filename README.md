# 五十音道場

平假名、片假名的全方位學習 App：關卡地圖、字表、翻卡複習、測驗、N5 單字與情境會話。

**線上使用**：https://kftseng2oo1.github.io/kana/

## 分頁與功能
- **🗺 關卡**：依あ行、か行…逐行解鎖，追蹤學習進度
- **📋 字表**：平假名、片假名、濁音一覽，點字可聽發音並標為已學
- **🃏 翻卡**：SRS 間隔複習，依「記不住／有印象／記住了」排 1、3、7 天後再出現
- **✏️ 測驗**：平→音、音→平、片→音、音→片、情境單字
- **📚 N5**：分類單字測驗，日→中、中→日、羅→日
- **💬 會話**：分類情境會話，可朗讀

## 技術與依賴
- 單檔 HTML PWA（`index.html` 內含全部 HTML/CSS/JS），`manifest.json` + `sw.js` 提供安裝到主畫面與離線快取。
- 日語發音使用 `speechSynthesis`（裝置需有日文語音，否則會提示）
- 進度存在 localStorage：`kd_l`、`kd_s`、`kd_q`、`kd_n5`
